Aufwärmen

04:00
🎯 Ziel: Ins Thema kommen — frei besprechen.
Warm up; discuss freely.
👥 So geht’s: Lest die Fragen laut und antwortet frei.
Read aloud, answer freely.
Diese Übung / this task:
😵 Blackout
„Was machst du, wenn dir ein Wort fehlt?“„Wie rettest du dich, wenn du steckenbleibst?“„Wie bleibst du im Redefluss, auch mit Lücken?“
🗣️ Umschreiben
„Kannst du Dinge mit anderen Worten erklären?“„Wie beschreibst du ein Wort, das dir fehlt?“„Wie umschreibt man präzise, ohne das Wort zu kennen?“

Wörter & Redemittel im Kontext

07:00
🎯 Ziel: Die richtigen Sätze für die Situation.
Key phrases.
👥 So geht’s: Lest die Sätze laut (🔊) und sprecht sie dem Partner nach.
Read aloud and repeat.
Diese Übung / this task:
Nach dem Wort fragen
  • Wie heißt das nochmal?
  • Wie sagt man das?
  • Ich weiß das Wort nicht.
Einfach umschreiben
  • So ein Ding für …
  • Das Gegenteil von …
  • etwas zum … (Kochen).
Zeit gewinnen
  • Moment, wie sage ich das?
  • Also, das ist …
  • Lass mich überlegen.
Weitermachen
  • Du weißt schon, was ich meine.
  • Egal, ich sage es anders.
  • Jedenfalls …
Definieren
  • Das ist das Wort, wenn man …
  • Das benutzt man, um … zu …
  • Ein anderes Wort dafür ist …
Vergleichen
  • Das ähnelt …
  • Das ist so ähnlich wie …
  • Stell dir vor, es wäre wie …
Den Partner einbeziehen
  • Hilf mir — wie heißt das?
  • Du kennst bestimmt das Wort.
  • Wie würdest du das nennen?
Fließend bleiben
  • Mir fällt das Wort nicht ein, aber …
  • Ich umschreibe es kurz: …
  • Sinngemäß meine ich …
Präzise umschreiben
  • Man könnte es umschreiben als …
  • Der Fachbegriff entfällt mir, gemeint ist …
  • Es bezeichnet den Zustand, in dem …
Elegant überbrücken
  • Mir liegt es auf der Zunge …
  • Wie auch immer man es nennt …
  • Nennen wir es der Einfachheit halber …
Metasprache
  • Mir fehlt gerade der treffende Ausdruck.
  • Ich greife zu einer Umschreibung.
  • Erlaube mir eine Annäherung: …
Souverän weiter
  • Das tut dem Gedanken keinen Abbruch, denn …
  • Zurück zum Kern: …
  • Unabhängig vom Wort …

Beispieldialog

07:00
🎯 Ziel: Hören, wie das Gespräch klingt.
Hear how it sounds.
👥 So geht’s: Lest den Dialog zu zweit mit verteilten Rollen — dann frei nachspielen.
Read in pairs, then improvise.
Diese Übung / this task:

gelb = wichtiges Wort · türkis = wichtige Wendung

A
Was brauchst du?
B
So ein Ding … wie heißt das nochmal? Zum Kaffee umrühren.
A
Ein Löffel?
B
Genau, ein Löffel!
A
Warum sagst du es nicht einfach?
B
Mir fiel das Wort nicht ein.

gelb = wichtiges Wort · türkis = wichtige Wendung

A
Was meinst du genau?
B
Mir fällt das Wort nicht ein, aber das benutzt man, um Essen warm zu halten.
A
Eine Warmhalteplatte?
B
Ja! Ein anderes Wort dafür ist vielleicht Stövchen.
A
Clever umschrieben.
B
Danke — so bleibe ich im Reden.

gelb = wichtiges Wort · türkis = wichtige Wendung

A
Wie nennst du das?
B
Der Fachbegriff entfällt mir, gemeint ist das Teil, das den Zustand beschreibt, in dem etwas überkocht.
A
Du meinst den Überkochschutz?
B
Exakt. Wie auch immer man es nennt — die Funktion ist klar.
A
Elegant überbrückt.
B
Das tut dem Gedanken keinen Abbruch.
💡 B hat das Wort vergessen und umschreibt es.

Rollenspiel

08:00
🎯 Ziel: Eine echte Situation spielen.
Act out a real situation.
👥 So geht’s: Wählt eine Karte, übernehmt die Rollen, spielt die Szene — dann Beispiel aufklappen!
Play it first, then reveal.
🥄 Gegenstand
Beschreibe ein Küchending ohne den Namen.
🅰️ Umschreiber🅱️ Rater
💬 So könnte es laufen:

Umschreiber: So ein Ding, zum Kaffee umrühren.

Rater: Ein Löffel?

Umschreiber: Genau!

Rater: Gut umschrieben.

🤝 Nach Wort fragen
Frag höflich nach einem Wort.
🅰️ Lerner🅱️ Partner
💬 So könnte es laufen:

Lerner: Wie heißt das Ding zum Haare trocknen?

Partner: Ein Fön.

Lerner: Ah, danke!

Partner: Kein Problem.

🔌 Definieren
Umschreibe durch Funktion.
🅰️ Umschreiber🅱️ Rater
💬 So könnte es laufen:

Umschreiber: Das benutzt man, um das Handy aufzuladen.

Rater: Ein Ladegerät?

Umschreiber: Ja — ein anderes Wort wäre Ladekabel.

Rater: Verstanden.

🗣️ Flüssig bleiben
Bleib im Reden trotz Lücke.
🅰️ Erzähler🅱️ Zuhörer
💬 So könnte es laufen:

Erzähler: Ich war beim … mir fällt das Wort nicht ein, beim Haarschneider.

Zuhörer: Beim Friseur?

Erzähler: Genau, jedenfalls …

Zuhörer: Erzähl weiter.

🧠 Abstraktes umschreiben
Umschreibe einen Begriff.
🅰️ Umschreiber🅱️ Rater
💬 So könnte es laufen:

Umschreiber: Gemeint ist der Zustand, in dem man anderen etwas unterstellt, ohne sie zu kennen.

Rater: Ein Vorurteil?

Umschreiber: Exakt — wie auch immer man es nennt.

Rater: Sehr präzise.

🎤 Souverän überbrücken
Elegant eine Wortlücke überspielen.
🅰️ Redner🅱️ Partner
💬 So könnte es laufen:

Redner: Der Fachbegriff entfällt mir — nennen wir es der Einfachheit halber Neugier.

Partner: Gute Lösung.

Redner: Das tut dem Gedanken keinen Abbruch.

Partner: Stimmt, weiter.

💡 Immer: einer kennt das Wort nicht und umschreibt, der andere rät.
