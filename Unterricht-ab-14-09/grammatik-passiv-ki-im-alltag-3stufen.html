Perfekt Passiv: ist + Partizip II + worden. Modalverb-Passiv: Modalverb + Partizip II + werden.

Diese Übung / this task:
🔄 „Die KI schreibt die E-Mail.“ → Passiv (Präsens)
➡️ wird — „Die E-Mail wird geschrieben.“
🔄 „Der Assistent spielt die Musik.“ → Passiv (Präsens)
➡️ wird — „Die Musik wird gespielt.“
🔄 „Roboter reinigen die Wohnung.“ → Passiv (Präsens)
➡️ werden — „Die Wohnung wird gereinigt.“
🔄 „Die App übersetzte den Text.“ → Passiv (Präteritum)
➡️ wurde — „Der Text wurde übersetzt.“
🔄 „Die KI generierte das Bild.“ → Passiv (Präteritum, + von)
➡️ wurde — „Das Bild wurde von der KI generiert.“
🔄 „Man speicherte die Daten.“ → Passiv (Präteritum)
➡️ wurden — „Die Daten wurden gespeichert.“
🔄 „Man hat das Bild generiert.“ → Passiv (Perfekt)
➡️ ist — „Das Bild ist generiert worden.“
🔄 „Man muss die Daten schützen.“ → Passiv (Modalverb)
➡️ müssen — „Die Daten müssen geschützt werden.“
🔄 „Man nutzt KI im Unterricht.“ → Passiv (Präsens)
➡️ wird — „KI wird im Unterricht genutzt.“
💡 werden konjugieren + Partizip II ans Ende.
