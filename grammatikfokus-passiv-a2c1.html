Grammatikfokus

Passiv

Wenn die Handlung wichtiger ist als die Person: Das Haus wird gebaut. Ein kleines Thema — klar erklärt, geübt und gesprochen. 🏗️

Niveau wählen

Die Regel in 3 Schritten

Wie sagt man, was gemacht wird? Ganz einfach:

1️⃣ Passiv = werden + Partizip II

„Das Haus wird gebaut.“ (Aktiv: Die Firma baut das Haus.)

Im Passiv ist die Handlung wichtig, nicht die Person. Form: eine Form von werden + Partizip II.

2️⃣ Die Zeiten

Präsens: „wird gebaut“ · Präteritum: „wurde gebaut“ · Perfekt: „ist gebaut worden“

Präsens wird/werden + Partizip · Präteritum wurde/wurden + Partizip · Perfekt ist/sind + Partizip + worden.

3️⃣ Wer? → von + Dativ · mit Modalverb

„… von Anna geschrieben“ · „Das Auto muss repariert werden.“

Wer handelt (optional): von + Dativ. Mit Modalverb: muss/kann … + Partizip + werden.

🎯 Aktiv vs. Passiv: Aktiv fragt „Wer macht?" – Passiv sagt „Was wird gemacht?". Das Hilfsverb ist immer eine Form von werden.

Wer? → von + Dativ.

A: Wer hat das geschrieben?

B: Es wurde von Anna geschrieben.

liefern wird geliefert

„Die Pizza wurde schnell geliefert.“

B: Es wird morgen geliefert.

bauen (Prät. Pl.) wurden gebaut

B: Das wurde in den 50ern gebaut.

B2/C1 · Modal, Zustand & Futur
Modalverb muss repariert werden
„Das Auto muss repariert werden.“
„Die Rechnung muss bezahlt werden.“
Modal + Partizip + werden.
🎭 Mini-Dialog

A: Und das Auto?

B: Es muss erst repariert werden.

💬 Was muss bei dir mal repariert werden?
Modal Vergangenheit musste … werden
„Das Auto musste repariert werden.“
„Alles musste neu gemacht werden.“
🎭 Mini-Dialog

A: War viel zu tun?

B: Ja, alles musste erneuert werden.

💬 Was musste zuletzt erledigt werden?
Zustandspassiv sein + Partizip
„Die Tür ist geöffnet.“
„Der Brief ist schon geschrieben.“
Vorgang (wird geöffnet) vs. Zustand (ist geöffnet).
🎭 Mini-Dialog

A: Ist schon offen?

B: Ja, die Tür ist geöffnet.

💬 Beschreibe einen Zustand mit „ist + Partizip“
unpersönlich es wird + Partizip
„Hier wird nicht geraucht.“
„Sonntags wird nicht gearbeitet.“
unpersönliches Passiv (ohne Subjekt).
🎭 Mini-Dialog

A: Darf man hier rauchen?

B: Nein, hier wird nicht geraucht.

💬 Was wird bei euch (nicht) gemacht? „Es wird …“
von vs. durch Person / Ursache
„Das Haus wurde von der Firma gebaut.“
„Die Stadt wurde durch das Feuer zerstört.“
von + Person · durch + Ursache/Mittel.
🎭 Mini-Dialog

A: Wer hat gebaut?

B: Es wurde von einer Firma gebaut.

💬 Wer oder was hat es gemacht? (von / durch)
Aktiv ↔ Passiv beides
„Die Blumen werden gegossen. ↔ Ich gieße die Blumen.“
„Beides ist möglich – je nach Fokus.“
Passiv, wenn die Handlung wichtiger ist als die Person.
🎭 Mini-Dialog

A: Aktiv oder Passiv?

B: Passiv, wenn die Handlung wichtiger ist.

💬 Sag denselben Satz aktiv und passiv.
Futur Passiv wird … werden
„Das neue Stadion wird gebaut werden.“
„Die Straße wird renoviert werden.“
Futur: wird + Partizip + werden.
🎭 Mini-Dialog

A: Und in Zukunft?

B: Ein neues Zentrum wird gebaut werden.

💬 Was wird in Zukunft in deiner Stadt gebaut werden?
man → Passiv unpersönlich
„Man spricht hier Deutsch → Hier wird Deutsch gesprochen.“
„Man isst viel → Es wird viel gegessen.“
„man“ verschwindet oft im Passiv.
🎭 Mini-Dialog

A: Welche Sprache?

B: Hier wird Deutsch gesprochen.

💬 Mach aus „man …“ ein Passiv.
